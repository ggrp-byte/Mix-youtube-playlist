🔒 Privacy Policy

⚠ Disclaimer: This privacy policy is provided for informational purposes only. The developer assumes no responsibility or liability for any data loss, account changes, playlist modifications, or any other consequences arising from the use of this extension. The extension is provided "as is" without warranties of any kind. By installing and using Mix Archive, you acknowledge that you do so at your own risk.

1. Overview

Mix Archive is a browser extension that saves tracks from YouTube Mix queues into a single archive playlist on the user's YouTube account. The extension does not operate any backend servers, does not collect analytics, and does not track user behavior.

2. Data We Do Not Collect

The extension does not collect, store, or transmit any of the following:

  • Personally identifiable information (name, email, address, phone number)
  • Financial information (credit card numbers, bank details)
  • Authentication credentials (passwords, tokens)
  • Private communications (emails, messages, chats)
  • Location data (GPS, IP address, region)
  • Browsing history (visited URLs, timestamps)
  • User activity (clicks, mouse movements, keystrokes)

3. Data Stored Locally

The extension stores the following data in chrome.storage.local, which remains on the user's device and is never transmitted to any server controlled by the developer:

  • Archive playlist ID and title
  • Language preference
  • Duration filter and skip window settings
  • Auto-capture toggle state
  • Deduplication index (previously saved video IDs)
  • Monthly usage counter (Free tier)

This data can be cleared at any time by removing the extension or clearing browser storage.

4. Third-Party Services

The extension interacts with two third-party services. The developer is not responsible for how these services handle your data:

  • YouTube (youtube.com): Reads the Mix queue and creates/modifies playlists using the user's existing browser session. See Google's Privacy Policy.
  • ExtensionPay (extensionpay.com): Verifies Free/Pro subscription status. Payment is handled by ExtensionPay. See ExtensionPay's Privacy Policy.

5. Permissions

storage Saves user preferences and deduplication data locally. No data leaves the device.
tabs Checks whether the active tab is a YouTube Mix page. URL check only.
alarms Polls ExtensionPay login completion (temporary, max 15 minutes). No data transmitted.
Host: youtube.com Reads Mix queue and writes to user's playlist via their own session.
Host: extensionpay.com Checks subscription status if user uses Pro features.

6. Remote Code

The extension does not use any remote code. All JavaScript is bundled within the extension package. No external scripts are loaded at runtime.

7. Children's Privacy

The extension is not directed at children under 13 and does not knowingly collect any information from children.

8. Data Retention

All locally stored data persists only as long as the extension is installed. Removing the extension deletes all stored data. The developer does not retain any data on any server.

9. No Warranty

The extension is provided "as is" and "as available" without any warranties, express or implied. The developer does not guarantee that the extension will function without errors, that YouTube's internal APIs will remain stable, or that playlist operations will always succeed. The developer is not liable for any data loss, playlist corruption, account restrictions, or any other damages resulting from the use of the extension.
